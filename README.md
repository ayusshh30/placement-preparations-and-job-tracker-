# Placement Preparation & Job Tracker

## About
Placement Preparation & Job Tracker is a web-based application designed to help students organize their placement preparation and job applications in one place. It aims to make the placement process easier by providing a platform to track coding practice, manage job applications, and monitor interview preparation.

## Features
- **Student Dashboard:** Overview of placement preparation and progress.
- **DSA Tracker:** Track solved coding problems and monitor topic-wise progress.
- **Job Application Tracker:** Manage company details, job roles, application status, and deadlines.
- **Interview Preparation:** Organize and track interview preparation.
- **Resume Management:** Manage and organize resumes.
- **Progress Tracking:** Monitor overall preparation progress.

## Tech Stack
- **Frontend:** React.js
- **Backend:** Java, Spring Boot
- **Database:** MySQL

## Getting Started

### Clone the repository
```bash
git clone https://github.com/YOUR-USERNAME/placement-preparation-job-tracker.git
```

### Navigate to the project
```bash
cd placement-preparation-job-tracker
```

### Run the frontend
```bash
cd frontend
npm install
npm run dev
```

### Run the backend
Configure your MySQL database connection and start the Spring Boot application.
