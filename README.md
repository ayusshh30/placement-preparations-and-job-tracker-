# Placement Preparation & Job Tracker

## About the Project

Placement Preparation & Job Tracker is a web-based application that aims to make the placement preparation process easier and more organized for college students.

During placement season, students have to manage several things at once, such as practising DSA, preparing for technical interviews, applying for jobs, keeping track of application deadlines, and updating their resumes. Managing everything separately can become confusing.

The idea behind this project is to bring these activities together on a single platform so students can keep track of their preparation as well as their job applications.

## Features

- **Dashboard:** View preparation progress and job application details in one place.
- **DSA Tracker:** Keep a record of solved coding problems and track progress topic-wise.
- **Job Tracker:** Add companies, job roles, application dates, deadlines, and application status.
- **Interview Preparation:** Organize interview preparation and keep track of completed topics.
- **Resume Management:** Manage resumes and keep different versions organized.
- **Progress Tracking:** Get an overview of placement preparation through statistics and charts.

## Technologies Used

- **Frontend:** React.js
- **Backend:** Java, Spring Boot
- **Database:** MySQL
- **ORM:** Spring Data JPA
- **API Testing:** Postman
- **Version Control:** Git and GitHub

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/placement-preparation-job-tracker.git
```

### 2. Open the project

```bash
cd placement-preparation-job-tracker
```

### 3. Run the frontend

```bash
cd frontend
npm install
npm run dev
```

### 4. Run the backend

Configure your MySQL database connection and start the Spring Boot application using:

```bash
mvn spring-boot:run
```
