# Placement Preparation & Job Tracker

## About
A web-based application aimed at helping students manage their placement preparation and job applications in one place. The platform will help students track DSA progress, manage job applications, prepare for interviews, and monitor their overall placement journey.

## Planned Features
- Student Dashboard
- DSA Progress Tracker
- Job Application Tracker
- Interview Preparation
- Resume Management
- Progress Analytics

## Planned Tech Stack
- **Frontend:** React.js
- **Backend:** Java, Spring Boot
- **Database:** MySQL
